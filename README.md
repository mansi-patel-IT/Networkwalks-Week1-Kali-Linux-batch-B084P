# Networkwalks Cybersecurity Internship – Week 1

## Project: Practical Lab Environment Setup

### 1. Objective
The objective of this task was to set up a cybersecurity practice environment using Kali Linux inside Oracle VirtualBox.

### 2. Tools Used
- Oracle VirtualBox
- Kali Linux
- 7-Zip
- Windows 11

### 3. Setup Steps
1. Downloaded and installed 7-Zip.
2. Downloaded and installed Oracle VirtualBox.
3. Downloaded the Kali Linux VirtualBox image.
4. Extracted the Kali Linux image using 7-Zip.
5. Added the Kali Linux virtual machine to VirtualBox.
6. Configured a NAT Network in VirtualBox.
7. Set the network subnet to `10.0.0.0/24`.
8. Configured the virtual machine's network adapter.
9. Configured Kali Linux network settings with IP address `10.0.0.2/24` and gateway `10.0.0.1`.
10. Configured a shared folder between Windows and Kali Linux.
11. Created a VirtualBox snapshot named **My fresh kali linux**.

### 4. Network Configuration

| Setting | Configuration |
|---|---|
| Network Type | NAT Network |
| Network Name | NatNetwork |
| Subnet | 10.0.0.0/24 |
| Kali Linux IP | 10.0.0.2 |
| Gateway | 10.0.0.1 |
| DNS | To be verified |

### 5. Learning Outcomes
- Learned how to install and configure Kali Linux in VirtualBox.
- Understood NAT Network configuration.
- Learned basic virtual machine networking.
- Practiced configuring IP and gateway settings.
- Learned about shared folders and virtual machine snapshots.
- Gained practical experience in setting up a cybersecurity lab.

### 6. Conclusion
Successfully set up a Kali Linux virtual machine environment using Oracle VirtualBox as part of Week 1 of the Networkwalks Cybersecurity Internship. This lab provides a foundation for practicing cybersecurity concepts in a controlled environment.
